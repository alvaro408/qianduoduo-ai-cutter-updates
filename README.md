# 钱多多 AI 智能混剪 · 软件更新

此公开仓库用于分发 Windows 版程序更新，应用源码单独维护。

[查看最新版本与更新说明](https://github.com/alvaro408/qianduoduo-ai-cutter-updates/releases/latest)

## 使用方法

首次使用或从旧版升级，下载 [Windows 完整安装包](https://github.com/alvaro408/qianduoduo-ai-cutter-updates/releases/latest/download/qianduoduo-windows.zip)，
解压后双击“钱多多AI智能混剪.exe”。首次使用按软件提示激活授权。
已有支持在线更新的版本，可点击软件右上角“检查更新”。软件启动后也会自动检查。

确认更新后，程序会显示下载进度，校验更新文件，退出软件后安装，再重新启动。
v2.1.1 起支持取消下载、网络错误自动重试和断点续传。
更新会保留本地配置、账号、授权及作品。请等视频处理、发布和扫码登录任务完成后再安装更新。

Release 中的 `qianduoduo-windows.zip` 是完整安装包，`qianduoduo-update.zip` 是程序更新包，`update.json` 是版本校验信息。
请通过软件内更新功能使用这些文件。

GitHub 网络不稳定时，可稍后重试或联系软件提供者。
